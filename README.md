# 数据统计分析工具

基于Flask的Web版本两组数据统计比较分析工具，支持数值变量和分类变量的统计分析。

## 功能特点

- 📁 支持CSV文件上传（拖拽或点击上传）
- 🔍 智能编码检测，支持多种中文编码格式
- 📊 数值变量分析：正态性检验、方差齐性检验、t检验/Mann-Whitney U检验
- 📈 分类变量分析：卡方检验
- 📋 生成标准三线表格式结果
- 🎯 现代化Web界面，响应式设计

## 安装要求

- Python 3.7+
- 所需依赖包（见requirements.txt）

## 安装步骤

1. 克隆或下载项目文件到本地目录
2. 安装依赖包：
```bash
pip install -r requirements.txt
```

## 使用方法

1. 启动Flask应用：
```bash
python app.py
```

2. 打开浏览器访问：`http://localhost:5000`

3. 使用步骤：
   - 上传两个CSV数据文件（支持拖拽上传）
   - 选择要分析的数值变量和分类变量
   - 点击"执行统计分析"按钮
   - 查看详细的统计结果和三线表

## 统计分析方法

### 数值变量
- **正态性检验**：Shapiro-Wilk检验
- **方差齐性检验**：Levene检验
- **组间比较**：
  - 满足正态性和方差齐性：独立样本t检验
  - 满足正态性但方差不齐：Welch's t检验
  - 不满足正态性：Mann-Whitney U检验

### 分类变量
- **卡方检验**：用于比较两组分类变量的分布差异

## 支持的文件格式

- CSV文件（.csv）
- 自动检测文件编码：UTF-8, GBK, GB2312, Latin1等

## 技术栈

- **后端**：Flask, pandas, numpy, scipy
- **前端**：Bootstrap 5, JavaScript, HTML5
- **统计分析**：scipy.stats

## 注意事项

1. 确保两个数据文件包含相同名称的列用于分析
2. 数据文件大小限制：16MB
3. 建议数据量：每组至少20个样本以获得可靠的统计结果
4. 系统会自动处理缺失值

## 故障排除

如果遇到编码问题，请确保CSV文件使用标准的中文编码格式（UTF-8或GBK）。
